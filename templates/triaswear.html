See a small piece of the Shopify code +

This is from the saved Halloween hero section. Liquid is Shopify’s template language. This part uses the button link set in Shopify, or the product collection if no link is set. 

{% liquid
  assign hero_link = section.settings.button_link
  if hero_link == blank
    assign hero_link = routes.all_products_collection_url
  endif
%}

STARTING FROM ZERO

We had a plan.
Then we learned.

When we started TriasWear, I had no experience running a clothing brand and no idea where to begin. I did a lot of research, made a plan, and learned through trial and error with the team.

I built the website on Shopify and wrote the code for the Halloween design. That meant bringing the brand, products, and shopping experience together, then continuing to work on the store as we grew.
